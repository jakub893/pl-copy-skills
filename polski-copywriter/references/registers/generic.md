# Rejestr generic — domyślny

- **Bezosobowo**, gdy odbiorcy to mieszana grupa: zero „zostałeś / wahałeś / poczułeś". Dozwolone: 2. os. czasu teraźniejszego („masz", „wiesz"), tryb rozkazujący („zobacz"), czas przyszły („zobaczysz"), bezokolicznik, „trzeba / da się / można".
- **Zdania 12–15 słów** w copy sprzedażowym; jedno zdanie = jedna myśl. Powyżej 25 słów dzielimy.
- **Bez myślników** „—" i „ – ". Zamiast: kropka, przecinek, dwukropek, nowa linia.
- **Bullety do 70 znaków.**
- **Bez żargonu:** jeśli termin wymaga specjalisty, zamień na prostszy odpowiednik.
- **Mniej formalnie** niż domyślna polszczyzna AI: bez „Państwo", „uprzejmie informuję", „pozostaję do dyspozycji".
- **Konkret bije generalia:** liczby, godziny, nazwy, sceny.

Zdania wzorcowe:
1. Rano budzi Cię zmęczenie, choć sen trwał osiem godzin.
2. O 14:00 kawa już nie działa.
3. Cena: 549 zł albo 3 raty po 199 zł.
4. Daj znać, jeśli coś jest niejasne.
